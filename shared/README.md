# 跨平台约定与样例

`shared/` 放可由不同语言读取的约定和数据。当前仅创建目录；格式在首次需要导入、导出或新增平台时确定。

| 目录 | 后续内容 | 用途 |
| --- | --- | --- |
| `contracts/` | 带版本的数据格式说明、JSON Schema 等 | 统一饮水记录、偏好与导入导出的语义 |
| `fixtures/` | 对应格式的 JSON 样例和规则输入 / 预期结果 | 给不同平台提供一致的验证依据 |

初始约定方向：饮水量统一以整数毫升表达；记录具有稳定标识；瞬时时间与用户时区分开表达；本地工作时段以本地钟面时间和明确时区解释。具体字段、时间编码和版本迁移规则在契约建立时一起确定。

共用的数据格式与内部 Swift 类型允许分开演进，由客户端适配层完成转换。新增样例时写明适用的契约版本与期望结果，避免依赖运行机器的时区。

平台代码放在 `apps/`，可复用 Swift 代码放在 `packages/`。未来服务端 API 协议在服务立项时定义。
