# 水序 macOS 交互与界面设计

版本：v0.2｜日期：2026-10-10｜关联：[功能方案](../../docs/product-design.md)、[提醒规则](../../docs/reminder-rules.md)。用户已选定[第 3 套界面方向](mockups/03-compact-overview.png)；[主稿细化](mockups/refined/README.md)覆盖全部设置分组和十八种菜单栏状态。

## 1. 界面原则与视觉方向

以「看一眼状态，记录一杯，回到工作」为主要路径。使用原生字体、表单、分隔与焦点反馈，信息层次依次为今日记录、提醒状态、快捷操作和其他入口。

三张[图标候选](../brand/icon-candidates/README.md)共同包含水滴与青蓝元素。建议界面强调色先参考候选 03 的深青与浅青绿，最终应用图标继续保留三种方向供选择。

| 元素 | 建议 |
| --- | --- |
| 字体 | 系统字体；重要累计数值使用清晰的数字样式 |
| 强调色 | 浅色模式先探索深青 `#006F70`；最终以实测对比度为准 |
| 辅助色 | 浅青绿用于轻量进度背景与局部强调；正文使用系统语义文本色 |
| 背景与控件 | 原生系统背景、表单和按钮；深色模式使用独立语义配色 |
| 动效 | 短暂状态过渡与进度更新；减少动态效果开启时直接切换 |
| 菜单栏符号 | 独立的单色水滴；状态用辅助标记及完整文字说明 |
| 反馈 | 记录成功在当前界面轻量反馈；常规操作支持撤销 |

彩色图标用于应用识别，单色符号用于菜单栏。候选 03 是横向展示稿，正式图标阶段需要单独制作合适的输出规格，保留原图。

## 2. 菜单栏面板

建议起始宽度 360 pt，按内容确定高度；最大高度约 560 pt，空间不足时滚动。间距以 8 / 12 / 16 pt 为初始节奏。尺寸是排版起点，随后验证不同显示缩放和语言。

| 从上到下 | 内容 | 交互与状态 |
| --- | --- | --- |
| 标题 | 水序 / Aqmino、小型更多菜单 | 更多菜单含说明、设置、退出 |
| 今日概览 | 「今日已记录」与累计数值、记录次数 | 设置目标后增加目标比例和进度；无目标显示累计 |
| 提醒状态 | 下一次时间或暂停、关闭、时段外等状态 | 状态有关的恢复、开启通知等操作出现在这一行 |
| 快捷记录 | 150 ml、250 ml、350 ml | 点击保存一条当下记录；容量可在设置修改 |
| 自定义记录 | 「自定义…」 | 打开容量输入 sheet |
| 轻量反馈 | 「已记录 250 ml · 撤销」 | 成功后保留 10 秒；期间不自动关闭面板 |
| 暂停与恢复 | 「暂停提醒…」或「恢复提醒」 | 暂停选项为 30 分钟、1 小时、今日 |
| 底部入口 | 「今日记录」「设置…」 | 打开或聚焦已有窗口 |

菜单栏关闭时不抢占其他应用焦点，也不主动展开面板。打开面板后可用 Esc 关闭，点击其他应用关闭面板。记录成功保留面板，方便撤销和确认。

### 状态文案与操作

| 状态 | 主文案示例 | 相关操作 |
| --- | --- | --- |
| 正常计时 | 下一次提醒 10:45 | 暂停提醒 |
| 稍后 | 将在 10:12 再提醒 | 暂停提醒 |
| 定时暂停 | 已暂停，10:30 恢复 | 恢复提醒 |
| 今日暂停 | 今日已暂停 | 恢复提醒 |
| 时段外 | 下次提醒 周一 09:45 | 修改时段 |
| 全局关闭 | 提醒已关闭 | 开启提醒 |
| 未授权 | 开启通知后接收喝水提醒 | 开启通知 |
| 权限拒绝 | 通知已关闭，仍可记录饮水 | 查看系统通知设置 |
| 仅通知中心 | 提醒将显示在通知中心 | 查看系统通知设置 |
| 自定目标达成并停止 | 已完成自定目标，今日提醒已停止 | 继续记录 / 修改目标 |
| 应用内到期 | 喝口水，稍作休息。 | 快捷记录或稍后 10 分钟 |
| 交付失败 | 提醒暂时未能发出 | 查看提醒设置 / 发送测试通知 |
| 保存失败 | 未能保存，请重试 | 重试；已确认累计保持不变 |
| 数据读取失败 | 记录暂时无法读取 | 重新读取 / 恢复有效备份 |

多种状态并存时，主文案遵循[提醒资格优先级](../../docs/reminder-rules.md)。权限提示作为补充信息可见，避免被长期暂停掩盖。应用内到期的稍后动作仅对当前机会有效；失效后返回最新状态。

## 3. 首次设置

采用一个简短设置窗口，建议宽约 440 pt。先展示应用作用和菜单栏位置，再提供星期、起止时刻和间隔。设置下方实时展示计划，例如「工作日 09:00–18:00，每 45 分钟；下次提醒 周一 09:45」。

用户主动点击「开启通知」时请求系统授权；「稍后设置」可以跳过。目标以「设置每日记录目标（可选）」折叠项提供，初始关闭。完成按钮只要求提醒字段有效。

通知请求失败或被拒绝后仍可完成引导，显示记录能力和设置入口。保存首次设置成功后标记完成；失败时保留草稿，不进入已完成状态。

## 4. 自定义记录与今日记录

自定义 sheet 包含容量输入、单位 `ml`、范围说明「请输入 1–2000 ml 的整数。」与「记录」「取消」。输入为空、非整数或越界时就地提示；无效或正在保存时不能提交。取消不改变累计与周期。

今日记录使用独立窗口，建议起始尺寸 440 × 520 pt，内容可滚动。顶部显示当前本地日期、累计和次数；列表按记录时刻倒序显示时间与容量。

| 情况 | 行为 |
| --- | --- |
| 没有记录 | 显示「今天还没有记录」，提供记录入口 |
| 删除单条 | 显示删除操作并保存；成功后更新统计与撤销反馈 |
| 删除失败 | 保留该行与累计，显示重试 |
| 最近删除撤销 | 在 10 秒内恢复原条目与时间；保存后重新评估目标资格 |
| 历史日期记录 | 首版保留数据，列表只展示今日；历史查看与补录在后续版本 |
| 跨日或时区变化 | 窗口更新日期、汇总与列表，不移动正在编辑的输入焦点 |

首版记录当前时刻，不提供记录时间编辑。误记可撤销、删除并重新记录。时间相关的撤销规则以提醒规格为准。

## 5. 设置窗口

建议起始尺寸 640 × 520 pt，使用清楚的分组导航与原生表单。偏好修改保留草稿，点击「保存」统一提交；「取消」放弃尚未保存的业务偏好。通知授权与登录启动属于立即执行的系统操作，旁边明确说明并展示实际结果，不由「取消」反向撤回。

| 分组 | 内容 | 反馈 |
| --- | --- | --- |
| 提醒 | 总开关、星期、时段、间隔、通知状态、声音、测试通知 | 校验及下一次时间预览；测试状态独立于正常周期 |
| 记录与目标 | 三个容量、自定目标开关与值、达标停止提醒 | 目标关闭后隐藏完成率，保留总量 |
| 通用 | 登录启动实际状态、跟随系统外观与语言的说明 | 启用失败或需要系统批准时显示操作入口 |
| 数据 | 本地保存说明、记录数量、删除全部记录 | 删除前显示影响范围并确认 |

删除全部记录的确认文案：「删除全部饮水记录？记录将无法恢复，提醒设置会保留。」只有用户确认并且完整删除事务成功后显示清空；保留防止旧通知重复操作的最小标记并失效旧未消费机会。处理中或失败时说明状态并提供继续完成入口，避免残留备份恢复旧记录。成功后重新计时，不补发过去机会。

测试通知文案：「这是一条水序测试提醒。」测试成功反馈为「测试提醒已发送，请查看通知中心」，不声称横幅已经显示。测试按钮执行期间禁用，并限制 5 秒内重复操作。

## 6. 系统通知交互

提醒内容建议使用完整、简短的句子：「喝口水，稍作休息。」系统负责显示应用名称与图标。动作包含发送时确定的容量，如「记录 250 ml」，以及「10 分钟后」。

正文点击打开面板，关闭通知不产生记录。按钮在不同 macOS 版本的系统界面中可能需要展开后才能看到，首次引导与说明中避免承诺固定按钮位置。可处理的已知旧提醒按当前时刻记一杯；失效动作只展示当前状态，具体资格以提醒规则为准。

通知允许请求 `.alert` 与 `.sound`，声音内容初始为空；开启声音仍服从系统权限。普通提醒使用普通中断级别。依据：[Apple 通知界面指导](https://developer.apple.com/design/human-interface-guidelines/notifications/)、[权限说明](https://developer.apple.com/documentation/usernotifications/asking-permission-to-use-notifications)。

## 7. 键盘、辅助功能与中英文

- 所有控件可以通过系统键盘访问；输入框有标签，按钮完整读出容量和操作。
- 应用窗口活动时支持设置快捷键 `⌘,`、退出 `⌘Q`；Esc 关闭面板或取消 sheet。首版不注册系统全局快捷键。
- 成功反馈和状态更新供 VoiceOver 读出，但不打断正在输入的内容。
- 累计值、进度与状态有文字表达，图形和颜色作为补充。
- 英文示例：「Recorded today」「Next reminder」「Record 250 ml」「In 10 minutes」。资源首期支持简体中文与英文，其他系统语言回退英文。
- 验证长英文、显示缩放、深色模式、提高对比度与减少动态效果；列表和表单可滚动，焦点顺序与视觉顺序一致。

## 8. 界面稿与后续状态

首批[三套界面稿](mockups/README.md)覆盖菜单栏面板与设置窗口的「提醒」分组。三套功能和示例数据一致，主要对比累计信息靠左 / 居中、分组边界与控件密度；编号按本次聊天图片的实际展示顺序保存。

示例为 2026-10-10 周六 10:30：今日累计 750 ml、3 次记录，每日目标关闭；工作日 09:00–18:00 每 45 分钟提醒，下一次时间为 2026-10-12 周一 09:45。面板和设置预览统一呈现时段外状态。

用户已选定第 3 套「紧凑秩序」，当前[主稿细化](mockups/refined/README.md)提供记录与目标、通用、数据三个设置页及十八种菜单栏状态，并包含目标开关、系统批准、删除确认、自定义记录和数据异常的具体表现。详细文案、控件状态、时刻关系和示例数据见[状态与交互规格](mockups/refined/state-spec.md)。

正常工作时段使用 2026-10-12 周一 10:30 的模拟场景；时段外沿用 2026-10-10 周六。保存失败保留已确认累计、暂缓调度并禁用新的写入操作；读取失败用未知占位，保留可用的重新读取和备份恢复入口。位图用于确认视觉方向，原生排版阶段以本页逻辑尺寸为起点，用真实系统控件验证文本、显示缩放和内容高度。
