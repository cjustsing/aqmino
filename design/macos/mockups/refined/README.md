## 关键交互

- 每日目标默认关闭；只有用户开启并自行填写后，才显示目标数值和线性进度。1500 ml 是演示用户输入。
- 150 / 250 / 350 ml 都是直接记录动作。保存成功才累计，成功反馈提供 10 秒撤销；记录后重新经过完整提醒间隔。
- 暂停、提醒关闭、权限不足、时段之外和目标达成均保留饮水记录能力。恢复暂停后重新计时；目标达成后通过修改目标设置调整提醒资格。
- 待授权提供「开启通知」；已拒绝和仅通知中心提供系统设置入口。面板打开时到期使用应用内提示。
- 保存失败保留已确认的 750 ml / 3 次；读取失败用「—」表示未知统计。可靠存储恢复前，记录、自定义和暂停等写入操作禁用，恢复入口保持可用。
- 登录启动和通知权限是立即执行的系统操作；只展示实际系统结果。「通用」「数据」示例没有业务草稿修改，所以保存按钮置灰。
- 删除确认显示 68 条记录的影响范围与无法恢复的后果；确认前数量仍为 68。提醒偏好保留。

详细文案、按钮状态、设置校验、时刻关系和边界见 [状态与交互规格](state-spec.md)。可复用的设计示例数据见 [states.json](states.json)，它是界面场景数据，独立于未来的生产持久化格式。

## 示例日期与生成记录

当前日期锚点为 **2026-10-10 周六**。为展示正常工作时段，大部分状态使用下一工作日 **2026-10-12 周一 10:30** 的模拟场景；时段外状态仍使用周六，下一次为周一 09:45。数据页的 68 条记录也是演示数据。

全部通过内置 **image_gen** 逐张生成，实际附加的视觉参考是选定主稿 PNG。两张状态稿经针对性修订，统一操作入口和禁用反馈；最终结果原样复制到本目录。完整生成与修订提示词见 `prompts/`，文件尺寸、校验值、源输出和场景对应关系见 [manifest.json](manifest.json)。

本轮是静态界面设计交付。位图用于确认视觉方向，原生实现时按[交互设计](../../interaction-design.md)中的逻辑尺寸和真实系统控件校准内容高度、键盘、辅助功能、显示缩放与深色模式。
