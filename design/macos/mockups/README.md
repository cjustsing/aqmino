## 共用功能与示例数据

三套沿用用户确定的「提醒 + 快捷记录 + 今日进度」：

- 今日累计 **750 ml / 3 次记录**，每日目标关闭，累计区域不显示完成率或目标进度环。
- 三个容量按钮 **150 / 250 / 350 ml** 直接记录一杯，250 ml 的强调是视觉优先级，不增加确认步骤。
- 保留「自定义…」「暂停提醒…」「今日记录」「设置…」入口。
- 提醒总开关开启；星期一至星期五 **09:00–18:00 / 每 45 分钟**；通知权限已开启，提示音关闭。
- 示例日期是 **2026-10-10，周六，10:30（Asia/Shanghai）**。当前处于提醒时段外，两处统一显示「下次提醒 周一 09:45」，对应 **2026-10-12 09:45**。
- 设置页使用侧边分组导航，当前展开「提醒」；「记录与目标」「通用」「数据」的详细内容继续沿用既有交互规格。
- 业务偏好以「取消 / 保存」处理草稿；通知权限旁说明「通知权限修改立即生效。」。

## 视觉约定

延续「极简、精致、Apple 原生」：系统字体、原生窗口控制、侧栏、表单、时间输入、开关和按钮；用间距、字级与细分隔表达层次。强调色先探索深青与淡薄荷，累计文字在不同方向中对比深青和系统正文色。

菜单栏使用单色水滴；应用图标候选继续独立保存，尚未选定正式图标。本次三张图标原图都作为品牌与色彩参考传入内置 image_gen，未作为界面布局源或编辑目标。
