# 品牌与界面资源

设计方向来自命名讨论：Aqmino · 水序、中英文品牌、Apple 原生风格、极简精致、低打扰。水滴与细时间圆环、青蓝与暖白可作为后续视觉探索的起点。

| 目录 | 保存内容 |
| --- | --- |
| `brand/` | 图标源稿、品牌色与使用说明、菜单栏符号源素材 |
| `macos/` | 菜单栏面板、设置、记录流程的界面稿与交互说明 |

后续平台确定后再新增相应设计目录。运行时要使用的图标、本地化和其他资源导出到对应客户端的 `Resources/`；在设计说明中标明源文件与导出目标。

已在 [brand/icon-candidates/](brand/icon-candidates/README.md) 保存用户选出的三张图标候选原图，并记录编号、尺寸与视觉方向。正式图标尚未确定。

[macOS 交互设计](macos/interaction-design.md)定义菜单栏面板、首次设置、记录、设置窗口、通知、状态文案和辅助功能。用户已从[首批界面稿](macos/mockups/README.md)中选定第 3 套「紧凑秩序」；[主稿细化](macos/mockups/refined/README.md)补齐三个设置分组和十八种菜单栏状态。原图、状态规格、示例数据、完整提示词和编号记录均保存在项目内。功能范围见[产品方案](../docs/product-design.md)。
